The PHP core smoke test runs without a database. The GitHub Actions integration suite requires ephemeral MySQL and starts the API over localhost HTTP **only inside CI**. Production configuration always requires HTTPS; this is not an exemption for cPanel hosting. CI captures email in a runner-temporary JSONL file and verifies registration, one-time token rotation, password reset, replay rejection, session revocation, encrypted outbox delivery, tamper rejection, retry limits and ciphertext erasure; no messages are sent to real mailboxes.
