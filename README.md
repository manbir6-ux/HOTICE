**Cinematic AI Video Studio — Flutter UI foundation**

HOTICE is a premium multi-AI video creation workspace. This repository contains the **first-stage, functional UI prototype**: navigation, forms, local project drafts, account profile switching, avatar presets, pricing selections and theme controls. The app does **not** yet generate video, accept payments, or authenticate users with a server.

## Guided 2D face capture beta — feature branch (28 Oct 2026)

This branch adds a consented, **on-device front-camera scanner** with ML Kit face detection, head-angle guidance, front portrait open-eye checks, consecutive-frame auto-capture, still-image revalidation, and five reusable front/side photo references per Actor. Native camera permissions are generated by `tools/configure_face_capture.py` after `flutter create .`. Live scanner is available in Avatar Studio.

**Important:** This is not full 3D reconstruction, a secure encrypted avatar vault, facial biometric verification, liveness proof or working AI-video avatar identity. Camera-based functionality still requires physical-device testing. Captured photos are temporarily cached unencrypted in this beta, so avoid sensitive use. Read [Smart reference implementation and limitations](docs/SMART_REFERENCE_ENGINE.md).

## Run locally
Install the Flutter SDK, then in this repository:

~~~sh
flutter create . --project-name hotice --platforms=android,ios
python3 tools/configure_face_capture.py
flutter pub get
flutter run
~~~

The platform scaffolds (Android/iOS) are intentionally not committed at this UI-first phase; the command creates them. The GitHub Actions workflow also prepares them before analysis and tests.
