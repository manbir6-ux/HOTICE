FREQUENTLY ASKED QUESTIONS

One studio. More creative control.

What is HOTICE?

HOTICE is a planned all-in-one studio for preparing AI video scenes, selecting compatible models, casting named actors and editing footage. The current build is a testing preview.

How does HOTICE help me choose a model?

HOTICE aims to compare supported input formats, reference limits, output durations and verified prices, then help you choose settings suited to your scene. Actual model support and cost depend on provider availability.

Will I get the best price and output quality?

Our goal is transparent pricing and practical tools for better results. A cheaper price or particular quality cannot be guaranteed; exact rates and capabilities will be displayed when providers are integrated.

Can I use multiple actors in one scene?

You will be able to assign multiple named roles where the selected model supports them. Actor creation on mobile will use guided capture, subject to camera permissions and verified quality checks.

Is video generation live now?

Not yet. Model selection and scene planning are currently previews. Media importing and playback may work locally in supported browsers.

Where are AI provider keys stored?

In the planned production system, providers will be configured through an authenticated server-side admin panel, never directly in mobile or web client code.
